# UI Stage 2 — Supervisor workflows

Stage 2 applies the shared UI foundation to the pages supervisors use every day.

## Updated workflows

- Supervisor mobile home remains intentionally reduced to Request Manpower, Attendance / End Time, WhatsApp, Settings and How to use.
- Request Manpower now uses the shared compact header, equal-height date/site controls, shared save bar and toast.
- Attendance now uses the same header and control sizing, while preserving offline save queue, evening mode and end-time submission behaviour.
- Daily Allocation uses the shared header, segmented view switch, equal-height controls and shared action bar.
- WhatsApp uses the shared header, segmented message type control, equal-height date/site controls and compact copy/share action bar.

## Shared components added

- Segmented navigation
- Section card
- Horizontal filter row
- Mobile bottom action bar with safe-area support
- Toast
- Supervisor content container

Safety status colours remain semantic and are not changed by the company theme.
