# UI Stages 3 and 4 — Management consistency and quality

## Stage 3

The shared UI system is progressively applied to management, directory, administration and report pages. Existing page IDs and handlers are preserved. Legacy headers receive the company theme, common controls receive equal sizing, and primary actions and toasts use the shared components.

## Stage 4

- Visible controls receive accessible names where the original markup omitted them.
- Keyboard focus is clearly visible.
- Mobile touch targets are at least 44px on standardised pages.
- The DPR save workflow now validates and writes linked activity progress into the schedule.
- CI installs both Chromium and WebKit so iPhone/Safari regression tests can run.
- Browser coverage includes standardised management pages and accessible form controls.
