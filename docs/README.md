## Maintaining documentation

Update affected documentation when behavior changes. Distinguish an implemented feature from a future requirement, keep references current and use sanitized examples.

Detailed internal business/technical handover documents, account inventories, credentials, live personnel data and private transaction originals belong in an approved access-controlled company location.
