# VCMS UI toolkit

Install: npm ci --prefix ui-toolkit
Build: npm run build --prefix ui-toolkit
Develop: npm run dev --prefix ui-toolkit
Node: 22.12+ or 24 LTS. All runtime packages and assets build locally; no paid API is needed.

The output is frontend/ui-preview/. This isolated component gallery uses sample data and does not import authentication, attendance, or worker APIs. Existing operational pages are not migrated automatically. Preview CSS (including Tailwind preflight) must not be injected wholesale into legacy pages. Use scoped styles or isolated React mounts during migration.

## Installed
- shadcn/ui: Button, Card, Dialog, Badge, Input, Checkbox. Source generated by the official shadcn registry CLI; MIT notice in resources.
- Aceternity UI: free Bento Grid from https://ui.aceternity.com/registry/bento-grid.json. No Pro components or licences purchased. Component source is included.
- Flowbite: package and dropdown example; initialise once after rendering each legacy page's controls.
- Lucide: vanilla and React packages; use explicit icon imports to avoid shipping the entire catalogue.
- AOS: package plus once-only fade-up example. Disabled for reduced motion.
- Tailblocks: upstream CTA source and MIT notice in resources; adapted CTA in the preview.
- Uiverse: AnthonyPreite checkbox source and MIT notice in resources; adapted with visible native input, keyboard focus and text label.
- Animista: local fade-in CSS adaptation and FreeBSD notice. No external animation service needed.

## Design resources (web tools, not npm packages)
- Realtime Colors: https://www.realtimecolors.com/ — test palette/contrast, then copy CSS tokens into src/styles.css. No user/site data upload is needed.
- Typescale: https://typescale.com/ — reference for a 16px base with restrained 1.2 heading scale. No subscription required by VCMS.
- Layoutit Grid: https://grid.layoutit.com/ — layout planning tool; output is ordinary CSS Grid. The preview uses responsive grid classes.
- SVGRepo: https://www.svgrepo.com/ — optional specialist asset catalogue. No SVGRepo asset has been copied into this installation. Check each selected asset's licence and save its notice before adding it. Lucide supplies the current icons.

## Usage rules
Keep Vortex red, charcoal and white. Use shared colour/spacing tokens. Use actual pending/done status text as well as colour. Keep focus styles and reduced-motion support. Show data immediately on operational screens; avoid scroll-reveal for essential records. Preserve upstream notices when distributing components. Never add paid components or required subscription services.

## Validation
Production build and browser interaction checks cover the shadcn dialog, checkbox and Flowbite dropdown. These checks do not validate a redesign of existing operational screens.
